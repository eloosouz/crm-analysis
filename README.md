# CRM Analysis

Análise de dados de clientes em R, utilizando SQL para calcular indicadores de recência, frequência e valor de compra (RFM).

## 📊 Sobre o Projeto
Este projeto tem como objetivo demonstrar o uso da biblioteca `sqldf` do R para realizar consultas SQL diretamente em dataframes, calculando métricas essenciais de CRM.

## 🛠️ Tecnologias Utilizadas
- R
- RStudio
- Pacote `sqldf`
- Git e GitHub

## 📁 Arquivos
- `Descomplica_RH.R`: Script principal com a lógica de análise.
- `vendas_amostra.txt`: Amostra dos dados utilizados.
